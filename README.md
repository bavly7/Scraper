# The Polite Scraper (A9)

## Target Classification
- **Target Site:** Books to Scrape (https://books.toscrape.com/)
- **Purpose:** A publicly available sandbox environment explicitly created for practicing web scraping.
- **Scope:** First 3 catalogue pages only (60 books total).
- **Data Collected:** Book title, product URL, raw price, availability status, rating, description, source page, and fetch timestamp.
- **Robots.txt Result:** Requested `https://books.toscrape.com/robots.txt` and received a 404 (No robots file found).
- **Policy:** I will not reuse this code on another site without checking its rules and terms first.
